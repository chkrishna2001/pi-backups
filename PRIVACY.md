# Privacy Policy: Pi Backups

_Last updated: 2026-10-27_

Pi Backups is a personal tool used only by its owner to back up the owner's own home server to the owner's own Google Drive.

## What data the app accesses

When the owner signs in with Google, the app is granted access to the owner's Google Drive so it can write, read and prune a backup folder. The app handles only the backup files it creates itself: encrypted archives of database dumps and server configuration.

## How the data is used and stored

- Backup files are encrypted on the owner's server before upload. They are stored only in the owner's own Google Drive.
- The sign-in token is stored only on the owner's own server and is used only to reach the owner's Google Drive.
- The app has no servers of its own and does not collect, receive or store any data outside the owner's Google Drive and the owner's own server.

## Sharing

No data is shared with, sold to, or disclosed to any third party. No analytics, advertising or tracking is used.

## Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access and deletion

The owner can revoke the app's access at any time at https://myaccount.google.com/permissions, and can delete the backup folder from Google Drive to remove all stored data.
